# Seed to Stars 26.3

A vanilla-plus Fabric modpack for Minecraft **26.3**: Create, Farmer's Delight and Croptopia farming, quarries and
power, new ores, bosses, extreme weather, Vulkan with shaders, and two long goals you chase with a friend:

- **Harvest Silo**: deliver 1,000,000 crops (any crop counts; crates and hay bales count 9).
- **Great Vault**: deliver 64 diamond, 32 emerald, 512 iron, 256 gold, 256 copper, 128 redstone, 128 lapis and
  4 netherite blocks.

Progress shows as boss bars. Keys (rebind under *Controls > Seed to Stars*): `;` hides or shows the bars, `'` prints
progress, `[` lists every boss and objective. The Advancements screen has a *Seed to Stars* guide tab and a
*Bosses & Objectives* tab.

## Install with Prism Launcher (auto-updates)

1. Install [Prism Launcher](https://prismlauncher.org/).
2. *Add Instance*: Minecraft **26.3**, mod loader **Fabric 0.20.1**.
3. Download `packwiz-installer-bootstrap.jar` from
   [its releases](https://github.com/packwiz/packwiz-installer-bootstrap/releases) and put it in the instance's
   `minecraft` folder (*Edit > Open folder*).
4. *Edit > Settings > Custom commands*, tick it, and set the **Pre-launch command** to:

   ```
   "$INST_JAVA" -jar packwiz-installer-bootstrap.jar https://raw.githubusercontent.com/omid-ctrl/seed-to-stars-26/main/pack/pack.toml
   ```

5. Use **Java 25** (Prism can download it: *Settings > Java > Auto-detect / Download*). Give it 8-10 GB.
6. Launch. The first start downloads everything; later launches pick up whatever was merged here.

Optional, in game: *Options > Resource Packs* to switch the look (Faithful 64x with its add-ons, Fresh Animations,
Fancy Crops), and press `I` to pick a shader (Vitrail runs shader packs on the Vulkan renderer).
[Sphax PureBDcraft](https://bdcraft.net/downloads/purebdcraft-minecraft/) works too, but only from BDcraft's own site.

## Repository

| Path | What |
|---|---|
| `pack/` | The packwiz pack: `pack.toml`, `index.toml`, one `.pw.toml` per mod / resource pack / shader |
| `datapack/` | The challenge datapack (generated by `tools/gen_datapack.py`) |
| `mod-keys/` | Source of `sts_keys`, the tiny client mod behind the three keys |
| `server/` | Dedicated-server tooling: op-only world switcher (`/function sts_server:world/list`), backups, systemd units |
| `tools/` | Generators: datapack, packwiz import, `.mrpack` export |

Want a mod in? See [CONTRIBUTING.md](CONTRIBUTING.md).

## Server notes

Dedicated servers need the same content mods. One caveat: Immersive Ores 26.3-0.2 lists a client-only mixin in its
common config, so on a dedicated server move `ToolOverlayRenderer` from `mixins` to `client` in
`immersiveores.mixins.json` (single-player is unaffected).

Premade challenge maps are not in this repo: they belong to their authors.
